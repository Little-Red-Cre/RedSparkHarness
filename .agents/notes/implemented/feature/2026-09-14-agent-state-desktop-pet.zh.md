# Agent Note：Agent 状态桌宠

状态：已实现

[English](2026-09-14-agent-state-desktop-pet.md) | 中文

## 问题

RedSpark 吉祥物原本是由 Conversation 持有的欢迎页装饰。它无法跟随 Agent 状态、持久化呈现选择、悬浮在活动任务旁，也无法在不修改 Conversation 代码的前提下接收独立提供的角色。

## 决策

创建 `dsh-client-ui-pet`，由它独占桌宠注册项、偏好、语义活动、文案和呈现。Conversation 声明一个 Session 可选的 `conversation.pet` slot，并请求 `hero` 或 `floating` 位置。内置 RedSpark 注册项提供正常版与 Q 版四帧图集。loopback 浏览器把同一份选择持久化到两个位置；远程浏览器只在自己的进程内保留选择。Session 状态派生待机、思考、等待、错误与完成；其他插件可以通过 `ctx.pet` 报告 Coding、工具工作或睡眠状态，功能包之间无需运行时导入。Electron 载体接收无路径穿越或查询参数的应用内绝对 PNG 路径，或受限的嵌入 PNG 帧；即使已移除 provider 在隐藏更新中留下过期图集，载体也会隐藏。

本决策只取代 2026-09-13 RedSpark 品牌笔记中“角色图片仅限空欢迎页”的备选结论。该笔记对产品身份、归属说明与服务商命名仍然有效。

## 考虑过的替代方案

**继续放在 Conversation 中：** 拒绝，因为角色注册、设置、素材、动画与 Agent 状态策略会让目标无关的 Conversation 外壳成为吉祥物所有者。

**让 Client 插件创建 Electron 窗口：** 拒绝，因为浏览器组合不能导入 Electron 或持有操作系统生命周期。桌面载体保持为可选呈现适配器，并只接收受限的已验证 IPC 消息。

**把吉祥物绑定到模型或主题选择：** 本次迭代拒绝。桌宠身份与呈现是独立用户偏好。

## 后果

发布的 Web 组合包含一个默认角色、两种同步形态以及「通用 > 个性化」设置界面。Electron 用户还可以在会话之外启用透明置顶桌面窗口；浏览器呈现卸载会隐藏该窗口。第三方插件可以用应用内图集路径或受限 PNG data 注册其他角色，也可以报告语义活动。当前四帧图集在多个语义状态间复用姿态，内置素材 URL 仍由 Web 部署持有。
